# Demo video: narration script

A 3 minute 0 second screen recording of the live app (<https://pazzo123.github.io/yieldgap-rwanda/>) with a
narration track. It has no captions or subtitles.

**Narration voice: synthetic.** The voice is Microsoft's neural voice `en-KE-AsiliaNeural` (Kenyan
English, female), generated with the `edge-tts` tool. The script was drafted with AI help and is
based on figures that were checked against the data (see [AI_USE.md](AI_USE.md)). The screen
recording was scripted and captured automatically from the live site; the position shown for
"Find my district" is a demo position (Musanze). The video itself does not mention the AI
assistance; the disclosure is in this repository.
