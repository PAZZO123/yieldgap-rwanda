# Demo video: narration script

A 3 minute screen recording of the app (the same files as <https://pazzo123.github.io/yieldgap-rwanda/>) with a
narration track. It has no captions or subtitles.

**Narration voice: synthetic.** The voice is Microsoft's neural voice `en-KE-AsiliaNeural` (Kenyan
English, female), generated with the `edge-tts` tool. The screen recording was scripted and captured
automatically. "Find my district" uses the browser's location, which was set to Musanze for the
recording, so the app finds Musanze exactly as it would for someone standing there.

The story follows Irish potato: Musanze (above the benchmark), Burera in Season B (on target),
then Kayonza (the largest potato gap), and ends with Boost yield on maize in Bugesera, because
Irish potato has no practice link strong enough to model.
